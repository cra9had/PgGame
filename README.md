# 🎮 PgGame — Personal Python Game Project

**PgGame** is one of my first “slightly serious” pet projects — a personal game built with Python and Pygame.  
It’s the project that made me fall in love with programming in general and Python in particular.

---

## 🚀 Overview

PgGame is a small-scale game backend that can store player data and game state.  
It was designed as a learning project to explore Python programming, OOP, and basic game logic.

---

## ⚙️ Installation & Setup

### 1. Clone the repository
```bash
git clone https://github.com/cra9had/PgGame.git
cd PgGame
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the game script
```bash
python main.py
```
